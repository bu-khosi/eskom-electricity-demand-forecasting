# eskom-electricity-demand-forecasting
Machine learning project forecasting Eskom residual electricity demand
1. Project Overview

This project focuses on analysing historical South African electricity data using Python and Machine Learning techniques.

The objective is to investigate electricity demand patterns, identify important variables influencing electricity demand, perform exploratory data analysis, and develop predictive models to support data-driven energy planning.

The project uses historical Eskom-related electricity data covering the period from April 2018 to March 2023.

2. Business Problem

Electricity demand forecasting and analysis are important for effective energy planning, resource allocation and operational decision-making.

The project investigates how historical electricity data can be used to understand demand patterns and evaluate the ability of machine learning models to predict the selected electricity target variable.

3. Project Objectives

* Analyse historical electricity demand patterns.
* Investigate data quality and missing values.
* Perform exploratory data analysis (EDA).
* Identify important variables influencing the prediction target.
* Develop and compare machine learning models.
* Evaluate model performance using appropriate metrics.
* Identify the most influential features using XGBoost.
* Communicate findings through data visualisations and analytical reporting.
